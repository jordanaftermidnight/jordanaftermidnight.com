# Web Design Project

## Browser Verification
All frontend changes require Playwright MCP verification before completion.
The global Stop hook enforces this automatically.

## MCP Usage
- **Playwright** (project): Browser verification, screenshots, DOM inspection
- **Figma** (project): Design-to-code, inspect components, extract assets
- **Firecrawl** (project): Scrape reference sites for design inspiration

## Council Routing
Frontend tasks auto-route to Gemini Pro. Use `--fan-out` for architecture decisions.
